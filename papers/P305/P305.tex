\begin{abstract}
The ground system for NASA's NEO Surveyor mission at Caltech/IPAC uses a heavily partitioned PostgreSQL database and Python tooling. This poster describes practical experience using large language models for code review, library migrations, schema and query design, and moving application database access to a stored-procedure API. The engineer defines the task, selects relevant context, and verifies each proposal. Controlled tests showed that AI can detect problems in application code but can also produce incorrect results when important context is missing. The poster presents a workflow in which AI drafts solutions, tests provide evidence, and the engineer decides what to implement.
\end{abstract}
